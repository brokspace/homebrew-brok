# AGENTS.md

This repository is a Homebrew tap. `Formula/*.rb` is generated by `scripts/update-homebrew-tap.py` in `brokspace/brok` (workflow **Update Homebrew tap**): do not edit formulae by hand; fix the generator instead. Pull requests need the `tests` workflow green (style, audit, install). Conventional Commits, `Co-Authored-By:` trailer for agents, no force pushes.
